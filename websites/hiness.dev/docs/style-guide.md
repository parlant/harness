# Design direction · royal gallery edition (`hiness.dev` & `hiness.app`)

**Reference:** The site keeps the clean page/data/layout split from the Parlant Jekyll template while embracing the chosen domains **`hiness.dev`** (CLI & OTP daemon) and **`hiness.app`** (`H.app` & `hiweb` workbench) with an understated, dark museum-gallery aesthetic ("Your Hiness"). From H itself, keep the strict structural grammar: an entry is a point, a continuation is a line, and a fork produces two labeled paths. Never draw a client as a branch or a fork as a second worker.

## Visual and interaction decisions

- **Dark museum-gallery palette (`data-theme="luxury"`):** Deep obsidian and charcoal gallery walls (`--paper: #0e0d0b`, `--surface: #161411`, `--surface-raised: #1d1a16`), warm parchment ink (`--ink: #f1ebe0`, `--muted: #b0a695`), burnished frame gold (`--accent: #d4af64`, `--frame-gold: #7f6535`), and muted gallery rules (`--rule: #2d2821`). No external web-font fetches, analytics, or runtime CDN requests. A locally drawn crowned `H` crest (`assets/mark.svg`) serves at masthead and favicon size.
- **Typography contrast (sans-serif primary, serif accents):** Primary display titles, headings, body copy, and UI controls use clean system sans-serif (`--royal-sans`). Commands, paths, kickers, and museum inventory labels use monospace (`--royal-mono`). System serif (`--royal-serif`: Iowan Old Style / Palatino / Georgia) is reserved strictly for select royal accents: italic display emphasis, royal house mottoes, and museum plaque titles. Prose stays near 65-70 characters per line.
- **Self-hosted public-domain museum artworks (`assets/art/*.webp`, `_data/artworks.yml`):** Curated pre-1900 royal portraits and court self-portraits (`PD-Art` / `CC0`), anchored by **Kunsthistorisches Museum Wien (KHM Vienna)** and **National Gallery of Ireland (NGI Dublin)** alongside the Prado, Uffizi, Rijksmuseum, and Princeton University Art Museum. Every painting is self-hosted as optimized WebP with full sitter, artist, year, museum, and inventory attribution in `_data/artworks.yml`.
- **Hero gaze interaction (`_includes/sections/hero.html`):** On the landing page, the frontmost portrait (*Prince Alessandro Farnese*, NGI Dublin `NGI.17`) uses an inline SVG almond-clipped iris/pupil overlay driven by a tiny, dependency-free inline `pointermove` listener (~30 lines, zero external packages). Pupils clamp to physiological excursion (`3.4px` horizontal, `1.35px` vertical in SVG viewBox units), return smoothly to neutral on `mouseleave`, and freeze completely when `prefers-reduced-motion: reduce` is active or scripts are disabled.
- **Royal Houses = Harness Profiles (`_data/houses.yml`, `_includes/sections/houses.html`):** Four royal houses map truthfully to `H.Harness` session profiles:
  1. **House of Habsburg** -> Built-in `coding` (`H.Harness.Coding`: `read`, `write`, `edit`, `bash`, `search_history`, `subagent`, hierarchical `AGENTS.md`).
  2. **House of Bonaparte** -> Starter extension template (`example.greeting.v1` via `H.Extension` + `H.Harness`).
  3. **House of Stuart** -> Custom read-only/steward `@behaviour H.Harness` profile.
  4. **House of Wittelsbach** -> Embedded `:harness` OTP application profile + custom `H.ExecutionEnv`.
- **Walkthroughs and disclosures:** Native `<details>` disclosures and pure-CSS radio tabs drive the installation selector, architecture lifetimes figure, and client demos without hydration or external scripts.
- **Accessibility and verification:** Wide layouts pair proposition and framed plates; narrow viewports stack proposition, actions, and full-width plates cleanly. Maintain one `<h1>` per page, a visible skip link, WCAG AA dark-surface contrast, keyboard focus outlines, straight quotes only, zero em dashes, and `make verify` compliance.

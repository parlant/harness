2. General information and local software boundary

Both hiness.dev and hiness.app are static, informational websites. We run zero advertising trackers, set zero first-party analytics cookies, and load zero third-party web fonts or runtime scripts from external CDNs.

The downloadable H software (h-daemon, hi, hiweb, and H.app) executes locally on your own computer and stores its session data in your local filesystem (~/.local/share/h by default). {{ c.company_name }} receives zero telemetry, transcripts, prompts, or credentials from your local H installation. When you configure an external model provider inside H, your local daemon sends model requests directly to the provider endpoint you selected under that provider's terms.

3. Website delivery and Cloudflare

These websites are delivered through the content delivery network and DNS edge of Cloudflare, Inc., 101 Townsend St, San Francisco, CA 94107, USA ("Cloudflare"). When your browser requests a page or asset, Cloudflare processes technical connection data required to transmit the response and defend the service against abuse:

  • IP address of the requesting device
  • Date and time of the request
  • Requested URL, referrer header, and HTTP status code
  • Bytes transferred, browser user-agent, and operating system

Processing is based on our legitimate interest in secure, fast, and reliable delivery of public documentation and release metadata pursuant to Art. 6(1)(f) GDPR. {{ c.company_name }} does not store per-visitor server access logs or profile visitors.
